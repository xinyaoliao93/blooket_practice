I don’t have a game code

  1. Ask your teacher or host for the current game code, join link, or QR code.
  2. If they haven’t started a game yet, wait for their invitation.
  3. Once you have an invitation, follow our joining guide.

You picked

My game code isn’t accepted

  1. Compare the code with your teacher’s current invitation. Re-enter it carefully on the official join page.
  2. Ask your teacher whether the game is still running and whether you can still join.
  3. If it still doesn’t work, ask your teacher to share the invitation again.

Still stuck? Ask your teacher or host for help.

The page won’t load

  1. Refresh the Blooket page once and try opening an ordinary website to check your connection.
  2. Try Blooket’s official connection checker for image or connection issues. It opens on their website.
  3. On a school device or network, ask your teacher for help if the problem continues.
Open official connection checker

Still stuck? Ask your teacher or host for help.

You picked

My homework link won’t open

  1. Open the full homework link from your teacher’s original message, or scan their homework QR code again.
  2. Ask your teacher to check whether the assignment is still available and to resend the link if needed.
  3. Use the homework invitation for this task. A different live-game code won’t replace it.
Read the official student guide

Still stuck? Ask your teacher or host for help.
